## Developer-community post

Title: A small language that compiles one blueprint into web UI, server code and storage

I'm building LLM-Language, an experimental programming language and compiler for
AI-written programs. Its current web profiles can turn a small source file into
a text-saving web application with history and an entry picker.

There is also a separate calculation core: programs are checked against explicit
contracts, and an independent checker decides whether to accept a proof certificate.
The generated website itself is tested, not mathematically proven end to end.

The examples run without a model account. Compilation produces source code;
running the generated web app still needs the documented host integration.
I'd especially appreciate feedback on the language boundaries and whether a new
contributor can follow the quickstart.

Repository: https://github.com/ShadowsInThe-Space/llm-language-mvp
Quickstart: https://github.com/ShadowsInThe-Space/llm-language-mvp/blob/main/docs/QUICKSTART.md
