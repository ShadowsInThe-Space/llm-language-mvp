# v0.7.0 — General web · Web Preview

Source release prepared on 2026-10-09. M3 covers issues #21, #22 and #32.
The gated workflow publishes only after the exact final commit passes all
required checks. [GitHub Releases](https://github.com/ShadowsInThe-Space/llm-language-mvp/releases)
is authoritative for publication status.

## Included

- Explicit `shared`, `client` and `server` execution locations, closed host
  operations and transitive effect/capability requirements. Requirements never
  mint identity, admin or database authority from browser-controlled values.
- General typed web and UI-library sources, immutable checked program IR,
  declarative forms/list/detail views, schemas and closed query forms. Saved-text
  history and a task planner use the same compiler, runtime and UI library.
- Server-side A1 parameter transforms with exact scalar signatures. Every
  transform reads original decoded inputs; replacements are applied together
  before typed SQL binding. Actual ordinary and callback edges determine the
  reachable Pure graph. The examples' shared `preserve_text` entry deliberately
  preserves data; nontrivial transformations have separate runtime regressions.
- Prepared insert, unique/list read, keyset pagination and revision-conditional
  update queries. Cursors cover the full effective ordering, including the
  primary-key tie breaker. No user-supplied SQL or target-code patch is accepted.
- Matching Python/TypeScript codecs for exact scalar, nominal record, Option
  and bounded list values. Int/Nat travel as canonical decimal strings within
  `[-9007199254740991, 9007199254740991]`, with Nat additionally nonnegative.
- Explicit Textarea controls preserve accepted Unicode, line breaks and empty
  strings up to 4096 UTF-8 bytes. Example lists use one row per page so maximum
  escaped text fits the wire budget. Older entries remain reachable with Next.
- Local Clear, failure preservation, stale-response rejection, hydration gates
  and visible confirmation counters for successful responses. Counters use no
  clock capability and are not the historical W2 timestamp receipt protocol.
- Canonical source/library snapshots, source positions, complete checked IR and
  a deterministic artifact manifest. Build checking recompiles the supplied
  sources and compares every generated artifact, rather than trusting a hash.

## Try it

Use the v0.7.0 tag once it is available in GitHub Releases:

```sh
git checkout v0.7.0
python -m pip install -e .
python -m llmlang compile-general-web examples/web/general/history.webapp \
  --library common=examples/web/general/common.webuilib \
  --pure-library helpers=examples/web/general/helpers.a1src --out build/general-history
python -m llmlang compile-general-web examples/web/general/tasks.webapp \
  --library common=examples/web/general/common.webuilib \
  --pure-library helpers=examples/web/general/helpers.a1src --out build/general-tasks
```

Compilation makes no model or network request and refuses existing output
directories. See [the general compiler guide](../GENERAL-WEB-PREVIEW.md) and
[the pinned host instructions](../../tests/general_host/README.md) for local
execution. The host imports generated modules unchanged, injects the actual D1
binding and allowed origin, and exposes only built client assets. Generated SQL,
server IR and Pure library snapshots are private build inputs.

## Bounds and compatibility

Requests and responses are bounded to 32768 UTF-8 bytes, JSON depth 32 and 4096
nodes. Program checking rejects worst-case action codecs that exceed byte/node
budgets. The general query target permits at most 100 positional bindings and
100000 UTF-8 SQL bytes per statement. Pagination provides stable per-request
ordering, not a database snapshot spanning concurrent writes.

Previous-page navigation retains at most 32 cursors and 262144 serialized UTF-8
bytes per list. Next continues beyond that window; Previous stops at the oldest
retained cursor. Clear resets the display and navigation without deleting rows.

Executable A1 libraries cannot raise trusted per-invocation ceilings of 100000
steps, 10000 collection expansions or call depth 64. The compiler and emitter
share portable validation, including unsafe integer and deep literal rejection.
Failures prevent SQL execution. The target range does not narrow the frozen A1
language's mathematical integer semantics.

P0, w1, w2, pkg1 and existing A1 IR/evidence contracts remain frozen. Historical
generated fixtures and the hosted W2 demonstration keep their existing identity.
The general history example does not replace W2 routes, UUID/idempotency behavior,
timestamp receipts, pagination protocol or database migrations. Its IDs are
entered explicitly. The task planner adds completion, priority and revision
checks; its edit form uses the displayed revision and explicit user inputs.

Both examples are public shared-data demonstrations. Authenticated/admin actions
require a trusted server authorization adapter and deny access if it is absent,
denies or fails. Real sessions, tenant policies, relations, general idempotency,
atomic transition plans and migration/recovery contracts remain M4 work.
Generated schemas are for fresh disposable databases, not upgrades of existing
installations. A zero-row conditional update is an explicit conflict, not a
multi-statement rollback guarantee.
