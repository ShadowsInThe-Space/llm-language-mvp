# v0.5.0 — Local libraries · Developer Preview

M1 delivers reusable local libraries for the pure P0 language. This is a
developer preview, not a stable general-purpose language or a release of the
fully autonomous Software Factory.

## Included

- M0 compatibility baseline for the historical P0, w1 and w2 profiles (#12).
- Strict `pkg1` manifests, explicit imports/exports, exact versions and local
  lockfiles; no network resolution or build hooks (#13).
- Deterministic dependency resolution and linking, including transitive and
  diamond dependencies (#14).
- Independent Source-to-Core binding checks before accepting whole-program
  P0 proof evidence (#15).
- Two distinct consumers of one shared pure library, with proof invalidation
  after a shared implementation change (#16).

## Try it

From a checkout of tag `v0.5.0`, install as described in [QUICKSTART](../QUICKSTART.md),
then on Linux run:

```sh
python scripts/demo_pkg1.py
```

The demo works in temporary copies, does not alter the examples and does not
contact an AI provider. It proves both programs, runs them, changes the shared
library, rejects stale locks/evidence, and verifies fresh evidence. See the
[pkg1 guide](../PKG1-GUIDE.md) for explicit CLI commands and expected results.

## Compatibility and limits

P0 semantics and w1/w2 generated output remain frozen by regression fixtures.
The distribution version is `0.5.0`; the unchanged web generator deliberately
retains `web.0.4.0` as its artifact identity.

Only local pure Int/Bool functions are supported by pkg1. There is no package
registry, recursive code, general web-package composition, or modular proof
reuse. Linux is the validated platform for package filesystem safeguards.
Proof claims are relative to the documented [trusted computing base](../PKG1-ASSURANCE.md)
and user-authorized contracts; the Python compiler/checker is not formally proved.

Historical `RELEASE.json` describes v0.2.0 evidence, not this release.
License terms are unchanged: see [LICENSE](../../LICENSE) and [NOTICE](../../NOTICE).

## Release gates

The complete test suite, Ruff, strict Mypy, the library demo, an installed-wheel
smoke test and an independent programming-languages review must pass before
publication. GitHub CI checks Python 3.12 and 3.13 with Node.js 24.

Local acceptance on 2026-09-20: **419 tests passed**, Ruff clean, strict Mypy
clean (27 source files). The wheel was installed into a fresh virtual environment;
imports resolved to its installed site-packages, both-consumer pkg1 demo passed,
and the unchanged w2 compiler generated a build that passed `verify_build`.
The release wheel includes the compiler templates and existing license notices.

[Independent PL/formal-verification review](../reviews/M1-REVIEW.md): no open
release blockers. This was an AI specialist review, not an academic endorsement
or a formal proof of the implementation.
