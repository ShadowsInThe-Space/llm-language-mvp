# v0.6.0 — Structured A1 language · Developer Preview

M2 makes the language useful for small, bounded domain-data transformations.
It remains a developer preview, not a formally verified general-purpose
language or a fully autonomous Software Factory.

## Included

- Nominal immutable records and closed variants with exhaustive matching.
- `Option<T>` and `Result<T,E>` built from the general variant machinery.
- Named non-recursive functions, explicit `Nat` refinement evidence and an
  acyclic call graph.
- Deterministic, used-only and budgeted specialization of explicit generic
  type and capacity parameters.
- `List<T,N>` with explicit capacity failure and optional indexing.
- `Text<N>` bounded by UTF-8 bytes, with distinct byte/codepoint operations,
  no implicit normalization or trim, and scalar-safe prefixes.
- Canonical `a1-ir-v1`, a deterministic reference interpreter, versioned
  structural checker evidence and an independent certificate checker.
- Standalone JavaScript target emission and differential execution tests for
  two consumers over two nominal records and capacities.

## Try it

The installed `llmlang` command exposes `check-a1`, `run-a1` and `emit-a1`.
Each command accepts canonical JSON A1 IR. `check-a1` can write a certificate;
`run-a1` executes only after a fresh successful check; `emit-a1` writes a
standalone JavaScript program for the selected entry and inputs.

## Assurance boundary

`proved` means the independent checker reconstructed the exact versioned A1
structural and supported local-contract evidence bound to the canonical module
hash. It does not prove the Python checker, the JavaScript runtime or arbitrary
business intent. Reference/target agreement is tested separately and is never
reported as proof. General recursion, dynamic dispatch, mutation, unbounded
collections and implicit null are rejected.

P0, w1, w2 and pkg1 remain frozen by compatibility tests. The A1 implementation
is additive; the historical web artifact identity remains `web.0.4.0`.

## Release gates

Publication requires every M2 issue closed as completed, complete Python
3.12/3.13 CI, Ruff, strict Mypy, installed-wheel CLI smoke tests, target
differential tests and an independent programming-languages/formal-verification
AI review with no open blockers. This review is not an academic endorsement.
